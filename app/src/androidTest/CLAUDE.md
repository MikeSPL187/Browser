# Инструментальные тесты (androidTest)

Подгружается, когда работаешь с файлами этой папки. Здесь — ловушки, найденные при запуске всех
1034 тестов в CI (S5, PR #121). Новую ловушку дописывай сюда коротко: симптом → причина → как правильно.

## Запуск
- Хелперы `grantNotificationPermissionForTests()`, `awaitAddressEditorFocused()`, `closeAddressInputButton()`
  и workflow `instrumented.yml` приходят с PR #121; до его слияния их нет на `main`.
- Локально не запустить (в облаке нет Android SDK и эмулятора). CI: workflow `instrumented.yml` —
  метка `instrumented` на PR, ночью на `main`, вручную с фильтром (пакет или `Класс#метод`).
- AndroidX Test Orchestrator с `clearPackageData`: каждый тест — свой процесс, данные и
  **runtime-разрешения сбрасываются**. Первая приватная вкладка просит `POST_NOTIFICATIONS` — выдай его
  заранее (`grantNotificationPermissionForTests()`), иначе системный диалог перекроет экран.
- Сводка — в логе задачи Report; известные падения — `scripts/ci/instrumented-baseline.txt`. Новую строку
  в baseline ради зелёного PR не добавлять: чинить. `-- flaky` — тест и проходил, и падал; новое падение
  перезапускается один раз, прошедшее со второго раза сводка показывает как Flaky.

## Ожидания вместо проверки «на первом кадре»
- Поле адреса получает фокус после начала анимации раскрытия, клавиатура на нагруженном эмуляторе —
  до ~10 с: `awaitAddressEditorFocused()` и `waitUntil`, а не сразу `assertIsFocused()`.
- Обзор вкладок (v4) масштабирует карточки при входе и **блокирует касания**, пока идёт анимация входа:
  касаться после `waitForIdle`/`waitUntil` по готовому состоянию.
- Восстановленная вкладка получает адрес на кадр позже — ждать текст, а не искать сразу.

## Семантика и поиск узлов
- `testTag` после `clearAndSetSemantics {}` в той же цепочке **отбрасывается** — `assertDoesNotExist()`
  по такому тегу проходит всегда. Если тег «не находится» или проверка «слишком легко зелёная» —
  смотри порядок модификаторов в `src/main`.
- `boundsInRoot` обрезается родителями (край карточки, сетки, экрана). Размер зоны касания проверяй по
  `SemanticsNode.size` / `touchBoundsInRoot`, а не по видимым границам.
- Кнопка закрытия редактора адреса и затемнение за ним имеют одну подпись: искать
  `closeAddressInputButton(context)` (подпись + `Role.Button`).
- Строки ниже экрана — `performScrollTo()` перед проверкой; карточки настроек (Q16c) — переключаемые
  узлы (`toggleable`). `performTextInput` вставляет в позицию курсора, а не заменяет текст.

## Поведение Vola, которое ломает старые ожидания Candy
- Обзор вкладок v4: сетка по умолчанию, стопки не рисуются (вернутся в S12), док снизу с «+».
- «Назад» на единственной вкладке уходит в систему. Меню — короткое (S4a).
- При выключенной анимации запуска старт из лаунчера открывает редактор адреса
  (`StartupAddressFocusMode`) — в тестах, которым это мешает, ставь `Never` в `setUp`.
- Оформление «Рама» по умолчанию (`previewTopInset` = 0); тестам вставок Gecko нужен «Воздух».
