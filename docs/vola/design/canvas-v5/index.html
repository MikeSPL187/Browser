Vola v5 — холст на утверждение

Версия 2: учтены решения владельца по черновику и исследование «Дизайн Vola v5: ориентиры». Главное: над страницей нет живого стекла (GeckoView рисует её в отдельной поверхности), поэтому панель — непрозрачная лента цвета сайта; размытие — только над экранами самой Vola и над снимком страницы.

Каждый экран — в рамке телефона 390 × 844 dp, тема переключается вверху. Значения — из system-v5.md; движения — из плана v5, раздел 5. Раздел «Движение» можно трогать пальцем.

Движение — попробуйте руками

Живая рамка с тремя вкладками. Коснитесь панели — капсула растянется в поле над клавиатурой. Ведите панель вбок — переключение вкладок, за последней появится новая. Потяните панель вверх — обзор; там свайп вбок или касание чипа меняет профиль. Держите ссылку 400 мс — предпросмотр. Тяните страницу вниз у верхнего края — обновление; прокрутка сжимает панель, касание — показывает. Пружины считаются по значениям из плана (масса 1, c = 2ζ√k).

Последнее движение: пока нет.

аСтарт и новая вкладка

Акцент профиля — на значке профиля, «Изменить», графике отчёта и лёгкой подложке сверху. Подложка плиток закреплённых — размытая фавиконка самого сайта (приём Zen: цвет без ручной настройки). Отчёт — переключатель 7/30 дней и «•••» со «Скрыть». Никакого промо.

бСтраница с панелью

Раскладка Safari «Bottom» в чистоте «Compact»: капсула 48 dp [щит с числом · домен · обновить/стоп] и две круглые кнопки 48 dp — вкладки и меню. «Назад» — системный жест, «Вперёд» — в меню. Лента непрозрачная, кромка 0,5 dp и тень; продолжается под навигацией. Текст — белый, если хватает затемнения ≤ 0,12 по светлоте OKLCH, иначе тёмный.

вВвод адреса

Список растёт снизу вверх: прямо над полем — «Лучшее совпадение» (здесь «Перейти к вкладке»), выше — вкладки, закреплённые, история, поиск, дальше всех — «Найти на странице». Поле остаётся капсулой у клавиатуры. Под подсказками — размытый снимок страницы под плотным материалом, а не живая страница.

гОбзор вкладок

Кнопки — у нижнего края: [+] слева, чип профиля по центру, [Готово] справа (Safari вернул «+» вниз после жалоб). Свайп по обзору листает профили — точки над чипом, неактивные серые 0,7. Поиск сверху, сегмент «Вкладки / Частные». Цвет группы — только рамка 2 dp и точка, акцент профиля — рамка активной вкладки и кнопки. «Закрыть все» — в «•••» с подтверждением.

дМеню

Верхний ряд круглых действий: «Вперёд», «Закладка», «Поделиться», «Скачать». Закладка меняет форму при сохранении: круг → скруглённый квадрат с заливкой. «Читать» и «Слушать» — рядом, дальше перевод, поиск по странице, «Скрыть отвлекающее».

еПанель защиты сайта

Два слоя, как у Brave, но спокойнее: статус, одно число, один переключатель; «Сайт работает неправильно?» сначала предлагает мягкий шаг. Во втором слое — уровень, cookie-баннеры, de-AMP, отпечатки одним переключателем, исключение HTTPS-only, сброс и «Скопировать отчёт о поломке» (по сети ничего не уходит).

жНастройки

Цветные плитки в стиле Safari, цвет — по разделу, а не по акценту профиля (палитра из 11 цветов, белый значок ≥ 3,4 : 1). Новые пункты: «Окрашивать панель в цвет сайта» и «Сайты с особыми настройками».

зЧастный режим

Всегда тёмный, холодный фиолетово-серый — не спутать с обычной тёмной темой. Цвет сайта не используется. В обзоре — сегмент «Частные» и «Закрыть все частные вкладки».

иПланшет

Панель сверху (решение владельца), два варианта, как в iPadOS 26.4: «Раздельно» и «Компактно». Когда боковая панель свёрнута, текущая группа видна чипом в полосе вкладок. Страница — карточка с отступом 8 dp и концентрическим радиусом. Узкое окно в режиме нескольких окон получает раскладку телефона.

При 100 % рамку можно листать вбок внутри блока.

кРежим чтения и прослушивание

Два входа: значок «Читать» в капсуле и пункт меню; «Слушать» — рядом. Мини-плеер — вторая строка над панелью. Настройки — нижним листом: шрифт, фон, текст до 250 %, всё запоминается.

л«Скрыть отвлекающее»

Меню → «Скрыть отвлекающее» → касание элемента → «Скрыть». Подсказка выбора — у верхнего края, потому что внизу панель (у Brave панель закрывает нижние элементы). Пока что-то скрыто, в капсуле — перечёркнутый глаз.

мОтчёт о приватности

7 или 30 дней, не больше трёх чисел, без оценок «сэкономленного времени» и без уведомлений. Частные вкладки не учитываются, данные — только на устройстве.

нПредпросмотр ссылки

Живое размытие страницы невозможно, поэтому приём Zen: страница уменьшается до 0,97 и темнеет, карточка вылетает из точки касания по дуге не выше 20 dp. В разделе «Движение» это можно потрогать.

оТёмная тема: два тона акцента

Решение владельца: заливка — глубокий тон с белым текстом, текст и значки — яркий тон. Рамка всегда тёмная, чтобы сравнить при любой теме холста. Графит в тёмной теме поднят до #66666F.

Система

Токены из system-v5.md — в текущей теме холста. Цвет сайта можно проверить своим цветом.

Vola v5 — черновик холста, версия 2. Сайты, домены и данные выдуманы. Код и изображения — оригинальные; шрифты Inter и Material Symbols Rounded подключены с Google Fonts.
