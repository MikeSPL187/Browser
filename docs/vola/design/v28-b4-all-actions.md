## Чего в v5 нет (доступно только через «Все действия»)

| Действие v4 | Рекомендация | Почему |
|---|---|---|
| Дублировать вкладку | **Оставить** — в «Дополнительно» меню v5 | Так в Safari и Chrome; польза ясна |
| Открыть в приложении | **Оставить** — строка в меню v5, только когда приложение есть | Привычка Android; без неё ссылки на приложения теряются |
| Команды топпингов (юзерскриптов) | **Оставить** — в «Дополнительно», только когда у скриптов есть команды | Иначе скрипты с командами бесполезны |
| Действия расширений Firefox | **Оставить** — в «Дополнительно», только когда расширения их дают | То же для расширений |
| Отложить вкладку, «Отложенные вкладки» | **Убрать** | В Safari нет; закреплённые сайты и группы закрывают ту же нужду |
| «Candy trail» | **Убрать** | Нишевая функция с именем Candy (бренд в UI запрещён) |
| Добавить капсулу сайта | **Убрать из меню** | Настройки капсул остаются; в меню — лишний пункт |
| Краткое содержание | **Убрать из меню до решения** | Нужно проверить, где считается (сеть или устройство) — приватность |
| Разделить экран | **Не нужно на телефоне** | v5 рисуется только на телефоне; планшет — v4 |
| Компактный режим | **Убрать** | Панель v5 сама сворачивается при прокрутке (V7) |
| Парковка и закрепление панели | **Уже убрано** (Б7, #338) | Жест v4 |

## Как сделать (после решения владельца)

1. Четыре «оставить» — строками меню v5 в «Дополнительно»; две условные строки (топпинги и
   расширения) появляются, только когда им есть что показать.
2. Строку «Все действия» и вызов меню v4 из `BrowserAddressChromeV5.kt` убрать.
3. Убранные функции остаются в v4 (планшет, флаг выключен), новых в v4 не добавляем.
4. Обход экранов и тесты меню v5 — под новые строки.
