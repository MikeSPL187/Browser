# Макеты, версия 4 (2026-09-30)

Владелец счёл v3 не дотягивающей до лидеров. Сначала изучили браузеры 2026 года
(`benchmark-2026.md`), затем приняли решения по оформлению (ниже) и перерисовали каждый из
63 экранов v3 на новом языке. Добавлены два экрана защиты. Итого 65 экранов v4, живой прототип и
доски выбора оформления.

Правило приёмки от владельца: v4 не может быть хуже v3 ни на одном экране. Каждый экран
отрисован в Chromium с настоящими шрифтами и значками и сравнён с v3 бок о бок (`cmp`-листы).
Если v4 проигрывала хоть в чём-то (пропала функция, образовалась пустота, съехала подпись),
экран переделывался.

Холст: https://claude.ai/artifact/CEgKgiZHg4zuju2u7ALZ8C (версия 25).
- Страница «Прототип и оформление» — живой прототип, варианты «Рама» и «Воздух».
- Следующие 15 страниц — экраны v4 по разделам.
- «v3 · архив» — прежние экраны для сравнения.

Исходники — `docs/vola/design/canvas/` (`W-*.dc.html`, `V4*.dc.html`, `vola4.css`,
`vola4-colors.css`), сборщики — `docs/vola/design/tools/`.

## Решения владельца

- **«Рама» по умолчанию.** Вся оболочка лежит на градиенте пространства, страница — карточка со
  скруглёнными углами. **«Воздух»** (страница на весь экран, цвет в ореоле панели) включается в
  Настройки → Внешний вид.
- **Тёмная тема всегда на чистом чёрном** (`#000000`), отдельного переключателя OLED нет.
  Карточки в тёмной теме — на приподнятой поверхности `surfaceContainer`, иначе они теряются на
  чёрном.

## Язык v4

- **Цвет.** Один исходный цвет пространства задаёт всю схему: Material Color Utilities,
  TonalSpot, спецификация 2025.
  - Основной цвет сохраняет насыщенность исходного (не ниже 48), контейнеры остаются мягкими.
  - Нейтральные поверхности чуть тонированы цветом пространства.
  - Ореол (aura) — три соседних оттенка, плавный градиент.
  - Успех и предупреждение согласованы с основным цветом; фон ошибки смягчён.
  - Все пары «текст — фон» ≥ 4,5:1 (`tools/contrast.py`).
- **Шрифты.** Manrope для интерфейса, Literata для чтения. Вес 500–700, девять ступеней шкалы
  (`vola4.css`, `.ty-*`).
- **Значки.** Material Symbols Rounded, 24 dp, вес 400; заливка — только у выбранного.
- **Форма.** Скругления 8–32 dp, карточки 24, листы 32; самоцвет пространства — скруглённый квадрат
  с градиентом основного цвета.
- **Глубина.** Три уровня тени и стекло не прозрачнее 84 %, чтобы текст читался на любой странице.
- **Движение.** Пружины M3 Expressive: быстрая, обычная и медленная (затухание 0,9, жёсткость
  1400 / 700 / 300) и эффекты (1,0 / 1600).
- **Эргономика.**
  - Внизу одна полоса, никогда не два ряда.
  - Переключатель пространств и Essentials — у большого пальца.
  - Выбор из 2–5 вариантов — группа кнопок M3 Expressive.

## Что стало лучше, чем в v3, по разделам

| Раздел | Главное изменение |
| --- | --- |
| Основа | Доска токенов показывает реальные значения схем трёх пространств (светлая и тёмная), шкалу шрифтов, формы, пружины с графиками, отступы с назначением, значки. Компоненты: четыре состояния адресной панели, кнопки, выбор, пространства, вкладки, списки, листы, уведомления, индикаторы. Единая схема пустых и ошибочных состояний |
| Браузинг | Страница — карточка в раме пространства; при прокрутке панель сжимается в капсулу; ссылка из буфера и «Перейти» — у строки ввода; поиск по странице и режим чтения внизу |
| Вкладки | Миниатюры без двойной рамки, переключатель пространств внизу, Essentials над ним; смена пространства перекрашивает весь фон |
| Новая вкладка | Essentials плитками в зоне большого пальца, «Продолжить» с миниатюрами, приватная вкладка на своём фиолетовом |
| Меню и сайт | Плитки-переключатели M3E, сведения о сайте и «рентген» трекеров, запрос разрешения с картой, Glance-подобный просмотр ссылки |
| Пароли | Заголовок в одну строку, фильтры без обрезки, проверка паролей с кольцом-оценкой, генератор, автозаполнение с ключом доступа |
| Перенос | Пошаговый импорт из Chrome, связывание устройств по QR без своего сервера |
| Инструменты | Группы вкладок, перевод на устройстве, скриншот всей страницы, кнопки Vola поверх плеера сайта, голосовой ввод |
| Библиотека | История, избранное, загрузки, отложенные — с фильтрами-чипами и цветом пространства у каждой записи |
| Настройки | Карточки разделов, «Внешний вид» с выбором «Рама»/«Воздух», темой, плотностью, палитрой и скруглениями; иллюстрация жестов |
| Фичи Zen | Компактный режим, Split View, Glance и темы на новом языке |
| Первый запуск | Чёрная заставка, приветствие с точками страниц, настройка с живыми превью тем |
| Защита (новое) | Опасный сайт, проверка файла перед открытием, только HTTPS, запертое пространство с биометрией |
| Тёмная тема | Чистый чёрный фон, карточки на приподнятой поверхности, миниатюры сайтов тоже в тёмной теме |
| Планшет | Боковая панель как в Zen: Essentials, вкладки с группами, пространства внизу; Split View с заголовком у каждой половины; настройки в две колонки с дополнительными параметрами |
