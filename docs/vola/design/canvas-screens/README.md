# Макет всех экранов Vola (23.10.2026)

Холст: https://claude.ai/artifact/JhnpiTiy1Z1oAaWArr7bzG (открывает владелец).
Здесь — его исходники, чтобы другие сессии могли читать и переносить экраны в код.

Макет построен на утверждённой системе v5 (`../system-v5.md`): Inter, тёмная тема `#1C1C1E`,
панель в цвете сайта, акцент профиля, пружины из `../../plan-v5.md` (раздел 5). Новых токенов нет.

## Как устроено

- Формат — `.dc.html` холста Claude Design: один файл — один артборд. Вне холста файлы не
  открываются (им нужен `support.js` редактора) — это исходник, а не готовая страница.
- `canvas.json` — расположение артбордов, ряды и подписи.
- `Bar.dc.html` — единый компонент нижней панели; его подключают все экраны со страницей и доска
  `Panel.dc.html` (13 состояний).
- Каждый экран телефона принимает `dark` и `accent` (шесть акцентов профиля). `DarkA`–`DarkD` —
  ряды тех же экранов в тёмной теме.
- Цвета — переменные CSS в `<helmet>` каждого файла, значения один в один из `system-v5.md`.
