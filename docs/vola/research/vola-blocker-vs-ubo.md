# Блокировщик Vola на Gecko и uBlock Origin: чем уступаем

_Исследование v5 · свой блокировщик, шаг 4 · 2026-10-11 · ветки #185, #188, #189 · uBO 1.75.0,
uAssets `05bc031a`, EasyList `54849f55`/`f1f8fe7c`. Только доклад: что закрывать до переключения
по умолчанию (шаг 5) — решает владелец._

**Коротко.** Блокировщик Vola уже режет то, что режет WebView-сборка: 266 тыс. хостов (EasyList,
EasyPrivacy, HaGeZi Pro, uAssets), 747 URL-правил uAssets, 39 тыс. адресных правил скрытия и 232
процедурных. Главное, чего нет по сравнению с uBO: **скриплетов** (9 278 правил uBlock filters — на
них держится реклама в видео YouTube и обход «выключите блокировщик»), **сетевых правил EasyList с
путями** (16 431 строка) и **общих правил скрытия** EasyList (13 642). Без первых двух на части
сайтов рекламы станет заметно больше, чем с uBO.

## 2. Чего нет

| Чего нет | Объём в списках | Что это даёт uBO | Насколько заметно |
|---|---|---|---|
| **Скриплеты** `##+js(...)` | 9 278 в uBlock filters (+29 исключений) | правка JS страницы: `json-prune`, `set-constant`, `abort-on-property-read`, `nowoif` — реклама в видео YouTube, антиблок-заглушки, всплывающие окна | **высоко**: YouTube-видео, новостные сайты с антиблоком |
| **Сетевые правила EasyList с путями и типами** (`/ads/banner.js`, `$script`, `$image`, `$domain=`) | 16 431 строка пропущена компилятором хостов | блок по адресу, а не только по хосту | **высоко**: реклама с собственных CDN сайтов |
| **Общее скрытие** (host `*`) | 13 642 EasyList + 272 uAssets | прячет типовые рекламные контейнеры на любом сайте | средне: в WebView работает (сканер токенов), в расширение не перенесено |
| `$redirect` / `redirect-rule` | 436 | подмена скрипта рекламы «пустышкой», чтобы сайт не ломался | средне: без неё блок скрипта иногда ломает страницу |
| Регулярные выражения `/…/` | 295 | редкие сложные адреса | низко |
| Процедурное скрытие сверх поддержанного (`:has`, `:style`, `:xpath`) | ~1 290 | скрытие по вложенности, правка стилей | низко–средне |
| HTML-фильтры `##^` | 345 | вырезание до разбора страницы (только Firefox) | низко |
| `$csp`, `$removeparam`, `$important`, `$replace` | 62, 11, 23, 7 | заголовки CSP, чистка параметров (частично делает Gecko), приоритет | низко |
| Блок всплывающих окон по спискам | 703 правила `popup` + 24 `popunder` | закрыть рекламное окно | средне: в WebView есть, на Gecko не перенесено |
| Списки uBO по умолчанию | uBO Privacy, Unbreak, Quick fixes, Badware, Peter Lowe | приватность, починка сайтов, вредоносные сайты | средне: часть покрывают HaGeZi и TIF (`threat_hosts.txt`) |
| Обновление списков | uBO — раз в несколько дней | свежие правила | средне: у Vola списки обновляются только с выпуском приложения |

## 3. Варианты перед шагом 5

**A. Сначала добить сеть и общее скрытие, потом переключать (рекомендую).**
1. Сетевые правила EasyList с путями и типами — компилятор по образцу `compile_advanced_filters.py`,
   проверка в `network_blocker.js` по тому же индексу хостов.
2. Общее скрытие — перенос сканера токенов WebView в `content.js` с теми же лимитами.
3. Всплывающие окна по спискам uAssets.
Потом шаг 5 с замерами на устройстве. Скриплеты — отдельным решением (см. C).
- Плюсы: на большинстве сайтов блокировка не хуже uBO. Минус: 2–3 PR до переключения.

**B. Переключать сразу после шага 3.**
- Плюсы: быстрее, APK −4,6 МБ, уровни сайта сразу управляют всей блокировкой. Минусы: заметно больше
  рекламы на сайтах с рекламой с собственных адресов; на YouTube реклама в видео вернётся.

**C. Скриплеты.** Небольшой собственный набор (`json-prune`, `set-constant`, `abort-on-property-read`,
`nowoif`) по правилам uAssets, исполнение через `contentScripts` расширения.
- Плюсы: закрывает YouTube и антиблок. Минусы: самая трудная часть — каждый скриплет пишется заново
  (код uBO GPL-3.0, не копируем), YouTube меняется часто и требует быстрых обновлений правил.
- Можно сделать после A, отдельной серией.
