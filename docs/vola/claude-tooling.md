# Инструменты Claude в репозитории

Всё здесь — для сессий Claude Code (оба аккаунта), а не для приложения: в APK ничего не попадает.
Ставить ничего не нужно — облачная сессия читает это из репозитория сама.

## Что уже есть

| Часть | Где | Зачем |
|---|---|---|
| Короткий `STATUS.md` | `docs/vola/STATUS.md` | на старте сессии читается только текущее (было 810 строк / 98 КБ ≈ 20–25 тыс. токенов на каждый старт) |
| Решения, заметки о среде, история | `docs/vola/decisions.md`, `environment-notes.md`, `history/` | читаются по необходимости, ничего не потеряно |
| Правила по разделам | вложенные `CLAUDE.md` в `app/src/androidTest/`, `ui/`, `browser/gecko/` | подгружаются только при работе с файлами раздела: ловушки Compose-семантики, ожидания в тестах, WebAuthn и release-сбои Gecko |
| Доска координации | описание issue #80 | одна таблица «кто что делает» вместо чтения 70+ комментариев |
| Навык `/claim` | `.claude/skills/claim/` | заявка и смена статуса строкой на доске без потери чужих правок |
| Навык `/handoff` | `.claude/skills/handoff/` | передача работы другой сессии по единому шаблону |
| Предохранители | `.claude/settings.json` | слияние PR через GitHub-инструмент спрашивает подтверждение владельца; пуш в `main` запрещён |

Навыки вызывает владелец (`/claim`, `/handoff`) или Claude сам, когда задача подходит под описание навыка.

## Что дальше (по плану, отдельными PR)

1. **Проверки Compose в `quality_gates.py`** — условное `clearAndSetSemantics` и `testTag` после него;
   исправление найденных мест (`WideAddressTabStrip.kt`, `hiddenUnderModal`, редакторы действий).
2. **Хук старта сессии + проверка перед пушем + `/preflight`** — Android SDK в облаке, гейты и
   юнит-тесты до пуша. Нужна сеть: владелец добавляет в настройках **каждой** среды (меню среды в

   `dl.google.com`, `maven.mozilla.org`, `jitpack.io`, `symbolication.services.mozilla.com`.
   Инструкция: https://code.claude.com/docs/en/cloud-environments#network-access
3. **Ночной smoke-тест release-сборки** (популярные сайты, вылет → стек в логе), итоги ночи —
   комментарием в issue, навыки `/ci` и `/crash`, помощник для логов на дешёвой модели.

## Проверка, что работает
- Новая сессия: на вопрос «что сейчас открыто?» отвечает по короткому `STATUS.md`, не открывая историю.
- `/claim` в новой сессии добавляет строку в описание #80, чужие строки не пропадают.
- Просьба «слей PR #N» вызывает запрос подтверждения в приложении (если в режиме Auto запроса нет —
  записать сюда и заменить правило на хук `PreToolUse`).
