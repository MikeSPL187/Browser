## 1. Правила работы
- **Перед каждой задачей порекомендуй Effort** (High по умолчанию; Extra — архитектура портов, много связанных файлов, повторно падающий CI, безопасность) — правило 10.
- **Заявка до первого коммита:** своя строка на доске #80 (`issue_write update` описания; навык `/claim`), по завершении — «ГОТОВО · PR #N» или «СНЯТО». Чужие файлы не трогай.
- **Один PR — одна тема**, маленькие. Для каждого PR: чек-лист ручной проверки на устройстве (что нажать — что должно произойти), Compose Preview для UI (светлая и тёмная тема), тест на каждый исправленный дефект (сначала красный, потом зелёный, где можно).
- **Сливать PR только по слову владельца.** Исключение — ведущая сессия J (`decisions.md`). Если ты не J, не сливай.
- Ветка: `claude/audit-fix-<тема>` от `main`. Если PR #456 (ветка `ccr-e991606b-dmjjn6`: отчёт, реестр, гейты, `sync.yml`) ещё не слит — начинай от этой ветки, чтобы реестр и патчи были под рукой, и укажи это в PR.
- Значения только через токены (`ui/theme`); никаких захардкоженных цветов и размеров. Каждая новая строка — сразу в `values/` и `values-ru/` (плейсхолдеры сохранять, plurals — one/few/many/other).
- Типы GeckoView/WebView — только в адаптерах движка. Новая функция — сначала порт (interface), потом Gecko; где WebView не умеет — скрывай пункт в UI.
- Перед завершением: `./gradlew testFullDebugUnitTest lintFullDebug` (если SDK есть; если нет — скажи прямо и положись на CI), `python3 scripts/ci/preflight.sh --fast` как `bash scripts/ci/preflight.sh --fast`.
- Не пушь в чужие ветки. Не коммить ключи, пароли, `local.properties`. Приватные вкладки ничего не пишут на диск.
- После каждого PR обнови **строку в реестре** (`открыто` → `в работе, PR #N` → `исправлено, PR #N` или `отклонено: причина`): автор реестра K разрешает править только колонку «Статус». Проверка `python3 scripts/ci/test_audit_register.py` должна проходить.
- Если находка при проверке оказалась неверной — запиши `отклонено: причина` и коротко объясни в PR. Не чини то, чего нет.
- Что решает владелец, а не ты (тип «решение» в реестре, например N-02, N-08, PM-05, DL-05): не делай, а задай **один** вопрос владельцу с рекомендованным вариантом. Правило 13: если рекомендован один вариант — бери его сам и пиши в PR, почему.
