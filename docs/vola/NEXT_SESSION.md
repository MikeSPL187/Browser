Продолжаем Vola — Android-браузер на GeckoView (форк Candy, MPL-2.0) в эстетике Zen Browser.
Я работаю только с телефона; источник истины для сборки — GitHub Actions. Отвечай по-русски,
коротко; экономь контекст: логи CI — только через grep и короткий хвост, картинки — только нужные
(контактным листом).

**Если ты в другом аккаунте.** Истории прошлых сессий у тебя нет — весь контекст в этом файле, в
`docs/vola/STATUS.md` и `docs/vola/ROADMAP.md`. Новую работу веди в ветке, которую назначила
сессия. Подписка на события PR может не сработать («Could not subscribe») — тогда проверяй CI сам
(`actions_list` по ветке, итог тура — в ветке `screenshots`), не через `sleep`: ставь себе
напоминание (`send_later`/`ScheduleWakeup`) на ~30 мин — столько идёт тур.

**Где мы.** План — `docs/vola/ROADMAP.md`, состояние — `docs/vola/STATUS.md`. Слиты Q1–Q15 и
Q16a–b (#31–#71, последнее слияние — 2026-10-04). Открытых PR с кодом нет. Итог тура — в ветке
`screenshots` (`crash-log.txt`, `a11y-report.txt`, `tour-log.txt`), а не в логе CI.

**Сначала прочитай:** `CLAUDE.md`; `docs/vola/STATUS.md` (разделы «Следующие шаги» и «Заметки о
среде»); `docs/vola/ROADMAP.md` (раздел 2 — очередь, раздел 6 — решения владельца).

**Задача этой сессии — Q16c, только после моего слова** (рекомендация прошлой сессии): главная
настроек карточками по W-Settings и остальные страницы на реестре `SettingSpec` — по одной странице
в PR; попутно долг Q1 (`Slider` со `SliderState`). Если я назову другой пункт — делай его. Перед
кодом — план из 3–7 шагов и рекомендация Effort.

**Планка: максимальная эффективность и продуктивность — как у лучших браузеров.** Ориентиры:
Safari (морфы и плавность), Arc и Zen (минимум интерфейса, пространства), Chrome (скорость и
надёжность), Firefox (приватность), Samsung Internet и Vivaldi (удобство и настройка).
- **Продукт.** Частое — в одно касание и у большого пальца; не больше двух касаний до любой
  функции. Мгновенный отклик: нет пустых экранов при старте, нет «прыжков» раскладки.
- **Плавность.** 60/120 к/с без рывков: состояния читаются в фазе отрисовки, `remember` и
  `derivedStateOf`, ленивые списки с ключами, нет аллокаций в `draw`; декодирование миниатюр и
  ввод-вывод — вне главного потока; память под миниатюры ограничена. При сомнении — метрики
  компилятора Compose.
- **Движение.** Только пружины `VolaMotion`; у переходов есть начало и конец в одном месте
  (морфы, а не появление из ниоткуда); тактильная отдача на ключевых жестах; «Убрать анимацию»
  уважается.
- **Работа.** Сначала самое ценное для пользователя; одна проверенная отправка лучше трёх
  догадок; ошибки CI — по логу, без перезапуска «на удачу»; повторяющееся — в общий компонент;
  каждое касание кода оставляет его чище (правило бойскаута).

**Правила (из `CLAUDE.md` и ROADMAP, обязательны):**
- одна фича — один PR; ветка от свежего `main`;
- код и коммиты на английском (Conventional Commits), описание PR на русском: что и зачем, как
  устроено, таблица «Vola vs лидер», ссылка на снимки, чек-лист проверки на телефоне, известные
  ограничения;
- только токены `ui/theme` (исключение — `// token-exempt: причина`);
- строки сразу в `values/` и `values-ru/` (формы множественного числа, число в каждой форме);
- для UI — `@VolaPreviews`; тест на каждое правило; шаг тура в `scripts/ci/capture_screenshots.py`;
- движки только через порты; новое не добавляется в `BrowserController`, трогаемая область
  выносится из него;
- не ссылайся на код из ещё не слитых PR (ветка — от `main`, иначе CI упадёт на компиляции);
  перед коммитом проверяй `git branch --show-current`;
- перед пушем: `python3 scripts/ci/quality_gates.py size|tokens --base origin/main|engine|brand`,
  `python3 scripts/test_translations.py`, чистые части — в JVM-проекте из STATUS («Заметки о
  среде»), повторное чтение своего диффа глазами ревьюера;
- CI зелёный; снимки эмулятора просмотрены глазами контактным листом (системный диалог может
  закрыть экран — проверяй, что на кадре именно тот экран); новых находок доступности нет;
- после открытия PR — метка `screenshots` и подписка на события; довести до зелёного.

**Порядок работы:** работай максимально продуктивно. Решения, которые нужны, — собери одним
сообщением с вариантами и рекомендацией.

**Сливать PR — только по моему отдельному слову.**

В конце работы обнови `docs/vola/STATUS.md`, `docs/vola/ROADMAP.md` и этот файл.

## Подготовка другого аккаунта (владелец, один раз)

1. В новом аккаунте claude.ai: *Settings → Connectors* → подключить GitHub тем же GitHub-аккаунтом
   **MikeSPL187** (или другим, у которого есть права записи в `MikeSPL187/Browser`) —
   https://claude.ai/connect-github. Если просит — установить Claude GitHub App на репозиторий.
2. Создать среду для Claude Code в облаке (claude.ai/code): сеть — по умолчанию (доверенные
   хосты); секреты не нужны — подпись и сборка идут в GitHub Actions.
3. Начать сессию с выбранным репозиторием `MikeSPL187/Browser` и вставить промпт выше.
4. Effort — **Extra** для Q16c (реестр настроек, много связанных файлов).

## Что должен сделать владелец (вне сессии)

- *Settings → Actions → General → Allow GitHub Actions to create and approve pull requests* — чтобы
  воркфлоу обновления GeckoView мог открывать PR.
- Релизный ключ (файлы присланы 2026-10-04): 4 секрета и переменная по `signing.md`, резервная копия
  `vola-release.jks` и пароля.
- По желанию: секрет `VOLA_PREVIEW_KEYSTORE_BASE64` (*Settings → Secrets and variables → Actions*);
  ветки слитых PR удаляются сами.
