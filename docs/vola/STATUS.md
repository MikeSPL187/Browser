## Дизайн

Согласованное направление: Zen Browser + Material 3 Expressive. Макеты (47 экранов, 11 страниц):
https://claude.ai/artifact/CEgKgiZHg4zuju2u7ALZ8C — исходники в `docs/vola/design/canvas/`
(`vola.css` — токены, `vola-icons.js` — иконки, `*.dc.html` — экраны).

Владелец: «более-менее нравится». Ключевые решения:

- Адресная панель внизу — плавающий стеклянный «остров»: кружок пространства слева, адрес по
  центру, вкладки и меню справа. При прокрутке сжимается в капсулу. Свайпы по ней листают вкладки,
  свайп вверх — обзор вкладок.
- Цвет пространства тонирует фон (мягкий градиент), кнопки и выделения.
- M3 Expressive: плавающая панель инструментов + квадратная FAB, морфинг формы выбранного элемента,
  группы кнопок.
- Шрифт интерфейса Manrope (кириллица), для чтения Literata. Сейчас в приложении системный Roboto.
- Никаких эмодзи, только иконки Material Symbols.

## Заметки о среде

- Android SDK в облачной среде нет: сборку и тесты проверяет CI (`build.yml`).
  `python3 scripts/test_translations.py` проверяет строки EN/RU локально.
- Логи CI из blob-хранилища скачать нельзя (403): смотреть через GitHub-инструменты,
  хвост лога job.
- Иконки пространств генерирует `scripts/workspace-icons/generate.py`
  (нужен доступ к raw.githubusercontent.com).
