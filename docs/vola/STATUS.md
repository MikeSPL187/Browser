## Действующие решения (полный журнал — `decisions.md`)

- **Сливать PR — по слову владельца; с 19:00 до 7:00 МСК (16:00–04:00 UTC) — без его согласия**, свои
  PR с зелёным CI и без конфликтов (2026-10-07). Выпуск релиза — только по его слову; сборку выпуска
  после разрешённого слияния сессия запускает сама (2026-10-06).
- Тёмная тема — всегда чистый чёрный, без переключателя OLED. «Рама» по умолчанию, «Воздух» — в настройках.
- Safe Browsing и локальный список опасных сайтов — всегда включены, без переключателя.
- Essentials — своя сетка у каждого пространства (новое получает копию «Личного»); П8 — свайп по
  нижней панели листает вкладки, пространства — в обзоре и по самоцвету.
- Стопки вкладок в обзоре v4 не рисуются; группы вкладок вернутся в S12 (три теста стопок — в baseline).
- Сторонняя открытая библиотека для KDBX допустима; без телеметрии и сторонних SDK.
- Палитры: шесть (Vola, Лёд, Сумерки, Бумага, Моно, Обои) + Dynamic/Neutral; в тёмной — чёрный фон.

## Среда — главное (остальное — `environment-notes.md`)

- В облачной среде нет Android SDK: `dl.google.com`, `maven.mozilla.org`, `jitpack.io` закрыты сетью
  среды. Сборку и тесты проверяет CI. Владелец может открыть их в настройках среды (см. `claude-tooling.md`).
- Логи CI читать через `get_job_logs` (`tail_lines`); артефакты из blob-хранилища недоступны, Summary задач
  через API не видно — нужное печатать в лог.
- Перед пушем: `python3 scripts/ci/quality_gates.py size|tokens --base origin/main|engine|brand` и
  `python3 scripts/test_translations.py`.
- Подписка на PR, открытые другой сессией, может не работать — проверять вручную.
