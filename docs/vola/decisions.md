  интерфейса сняты: «Рама»/«Воздух», чистый чёрный без переключателя, П8, Essentials по пространствам.
  Нынешний интерфейс работает как есть, пока его экран не заменён. Решения:
  - **Фундамент — расширенный:** движок, порты, CI, подпись, приватность, журнал сбоев, инструменты
    Claude + слой данных + движки защиты + обход экранов.
  - **System WebView — режим поддержки:** сборка и CI остаются, новые функции только для Gecko.
  - **Блокировка:** защита Gecko + наш блокировщик со списками EasyList/EasyPrivacy/uBO; uBlock Origin не встраиваем.
  - **Оформление:** тёмная тема тёмно-серая, как в Safari; шрифт Inter Variable; панель в цвете сайта.
  - **Бюджеты качества — как предложено** (`plan-v5.md`, раздел 7). UI-PR проверяются видео из CI,
    preview-APK и чек-листом.
  - **Организация вкладок:** профили как в Safari вместо пространств, группы внутри, свои закреплённые сайты.
  - **Функции:** приняты ядро (панель со свайпом, адресная строка, обзор с поиском, приватный режим),
    защита (панель сайта, отчёт), чтение (прослушивание, «Скрыть отвлекающее»), Glance, загрузки, тянущееся
    обновление, перевод на устройстве, проверка паролей. Passkeys — исследование после ядра.
    Split View и компактный режим отложены.
  - **Синхронизация:** QR в одной сети, затем WebDAV/Nextcloud, сквозное шифрование.
  - **Порядок:** гейты бюджетов → холст v5 → токены и флаг `ui.v5` → ядро экран за экраном.
  - `CLAUDE.md` — переписать раздел «Дизайн» сразу.
