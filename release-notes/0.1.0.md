# Welcome to Vola

Vola is a calm, private Android browser built on GeckoView, with Android System WebView as a lightweight alternative engine.

## What’s inside

- Gesture-first browsing with a floating address bar and a visual tab overview
- uBlock Origin and cookie-banner protection out of the box, plus Firefox extensions
- Isolated profiles, private tabs that stay in memory, and local tracker blocking
- Stacks for grouping tabs, Trails for your browsing journeys, and Reader mode

## Coming next

- Russian interface
