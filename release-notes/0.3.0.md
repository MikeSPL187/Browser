# Vola 0.3.0

Больше сотни исправлений по проверке каждого экрана, голосовой поиск и журнал сбоев.

## Новое

- Голосовой поиск в адресной строке: распознавание только на телефоне, без отправки голоса в облако
- Журнал сбоев: если Vola закрылась с ошибкой, при следующем запуске можно посмотреть и скопировать отчёт. Он хранится только на телефоне
- Vola предлагает сохранённый пароль прямо на поле входа сайта
- Свежая сборка GeckoView 157 с последними исправлениями безопасности

## Исправлено

- Вход в Google больше не закрывает браузер
- Касания на странице попадают точно туда, куда нажали, в «Воздухе» и компактном режиме
- Панель не висит над формой, пока открыта клавиатура; только что открытая страница больше не бывает пустой белой карточкой
- Первый запуск: знакомство снова показывается после установки, не пропускает нажатия к странице под ним, «Назад» работает, ссылка из другого приложения открывается сразу, а знакомство подождёт до запуска с главного экрана
- Пароли: автоблокировка срабатывает и после сна телефона, из хранилища можно выйти, понятнее импорт
- Приватные вкладки, Split View, Glance, пространства, отложенные вкладки и новая вкладка — замок, удаление, восстановление и TalkBack
- Загрузки: проверка файлов, APK, сохранение в папку, поиск и группировка по дням
- История и избранное: удаление, отмена, порядок и повреждённые записи
- «Память страниц» снова запоминает открытые страницы
- Режим чтения, поиск на странице, «О сайте», разрешения сайтов и страницы ошибок
- Видео и музыка: звук в фоне не останавливается сам, полноэкранное видео в System WebView, перевод и «Поделиться»
- Смена движка не теряет вкладки и не обрывает идущие загрузки
- Приватная клавиатура без запоминания ввода в адресной строке и в поиске на странице
